The Nim Team is happy to announce version 2.4.2, the first patch release for our stable release, Nim 2.4.

It comes two weeks after the 2.4.0 release and it contains [65 commits](https://github.com/nim-lang/Nim/compare/v2.4.0...v2.4.2), bringing bugfixes and improvements.

If you missed the 2.4.0 release and want to see what's new in Nim 2.4, [check this article](https://nim-lang.org/blog/2026/10/28/nim-240.html).





## Installing Nim 2.4.2


Check out if the package manager of your OS already ships version 2.4.2 or
install it as described [here](https://nim-lang.org/install.html).

If you have installed a previous version of Nim using `choosenim`,
getting Nim 2.4.2 is as easy as:

```bash
$ choosenim update self
$ choosenim update stable
```

**NOTE:** Make sure that the version of choosenim you have installed is 0.8.5 or higher, otherwise visit [choosenim's repo](https://github.com/nim-lang/choosenim) and see there how to re-install it first, before updating Nim.

Alternatively, you can download Nim 2.4.2 from
[our nightlies builds](https://github.com/nim-lang/nightlies/releases/tag/2026-11-13-version-2-4-b27dcb4f70883978e984e427cc24b64eeb7c875f).
